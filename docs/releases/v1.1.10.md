# NodeBeacon 1.1.10 production acceptance

## Release decision

- Release date: 2026-08-24 (Asia/Shanghai)
- Application image: `nodebeacon:git-03b75b53a9b0`
- Application commit: `03b75b53a9b0d94874008e863dad990abaa8e04e`
- NodeBeacon Web commit: `6a676a09c0fe967da43dbc7176754c9c8a633f9c`
- NodeBeacon Deployment revision: `98`
- Scope: retire the leftover React 18 shell. Fastify now serves only the
  React 19 `apps/status-web` bundle for `/`, `/login`, `/admin/*` and
  `/nodes/*`. `apps/web`, `/legacy/` assembly and the dual-shell Playwright
  setup were removed. No Komari RPC2 or Agent endpoints were added.

## Validation completed

- Local gates passed for the application commit: `pnpm lint` (zero errors; 24
  preserved upstream warnings), `pnpm typecheck`, 141 API tests, 13 frontend
  library tests, `pnpm build` including `scan:forbidden`, a clean
  `pnpm exec playwright test --project=chromium` run (30/30 against the API
  on port 3001), and `git diff --check`.
- `scripts/deploy.sh --plan` resolved version `1.1.10`, the complete application
  SHA, and immutable image `nodebeacon:git-03b75b53a9b0`. The full deployment
  script and `./scripts/verify-production.sh` then passed from the clean
  detached release checkout. Production reports 1/1 Ready.
- Real Chromium against production: `/` is the React 19 public shell
  (`entry-index-M6e5NAt2.js`, five node cards). `/nodes/rs1000` stays in that
  shell (`data-page="node-detail"`, six whitelist charts, no
  `.detail-main-content`). `/login` and unauthenticated `/admin` use the same
  bundle. `/legacy/` and `/legacy/assets/index.js` no longer serve React 18
  assets; the path falls back to the React 19 SPA and renders the in-shell
  404. `/instance/rs1000` still returns 308 to `/nodes/rs1000`.

## Repository boundaries

- `xljya/NodeBeacon` is the main project and the only repository deployed to
  RS1000 and served on `monitor.liucf.com`. This release deployed only that
  repository.
- `xljya/NodeBeacon-Web` branch `nodebeacon` is a supporting, maintainable
  Komari-derived frontend source. Its exact commit
  `6a676a09c0fe967da43dbc7176754c9c8a633f9c` remains vendored into NodeBeacon;
  the repository itself is not independently deployed to any machine or domain.
- `xljya/NodeBeacon1` is a supporting historical archive for the pre-migration
  project and infrastructure. It is not part of the current build or data
  plane and is not deployed to any machine or domain.
