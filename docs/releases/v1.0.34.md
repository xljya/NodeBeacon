# NodeBeacon 1.0.34 production acceptance

## Release decision

- Release date: 2026-07-30 (Asia/Shanghai)
- Application image: `nodebeacon:git-f85965ca89e0`
- Application commit: `f85965ca89e069b0988aa62dca3b6b094e09db19`
- NodeBeacon Deployment revision: `73`
- Scope: establish a locale-aware UI typography system. English remains Space
  Grotesk, telemetry stays JetBrains Mono, and Simplified/Traditional Chinese
  use the matching Noto Sans webfont plus system fallback stack. The language
  switch now updates the document `lang` attribute, localized data units have a
  CJK fallback, and the Chinese mobile Login button remains single-line.
- No API, SQLite schema, Kubernetes resource, Secret, or monitoring behavior
  changed in this release.

## Validation completed

- Local gates passed: `pnpm lint`, `pnpm typecheck`, 95 API tests, `pnpm build`,
  Chromium Playwright suite (26/26), Kubernetes kustomize render, and
  `git diff --check`.
- Added Chromium coverage verifies that selecting Simplified Chinese changes
  `html[lang]` to `zh-CN`, renders the Noto Sans SC UI stack, and keeps the
  status-page Login button unwrapped.
- `scripts/deploy.sh --plan` and `scripts/deploy.sh` completed the immutable
  image build, k3s import, rollout, readiness, and smoke checks.
- `scripts/verify-production.sh` passed. Production Deployment is `1/1` Ready
  and the deployed image annotation points to the exact application commit
  above.
- Real Chromium checks at `1440px` and `390px` verified five live node cards,
  Noto Sans SC and JetBrains Mono loading, the `zh-CN` document language,
  locale-aware UI and data font stacks, and a `94px × 38px` single-line Chinese
  Login button.
