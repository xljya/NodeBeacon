# NodeBeacon 1.0.7 production acceptance

## Release decision

- Release date: 2026-07-15 (Asia/Shanghai)
- Application image: `nodebeacon:git-4ef7e93c726c`
- Application commit: `4ef7e93c726cce5a82e8a27f11243f0278404505`
- NodeBeacon Deployment revision: `43`
- Scope: Node Detail V2 public API and UI, registry detail migration, five-node
  fast Prometheus scrape, and a separate retention change.

## Validation completed

- Local gates: `pnpm lint`, `pnpm typecheck`, API tests (75), production build,
  and Playwright E2E (13/13) passed before deployment.
- Production application checks passed: `/healthz`, `/readyz`, all five public
  detail and series endpoints, anonymous admin rejection, and unknown-node 404.
- A one-minute 10-client load check had no 5xx or network failures. Route-limit
  429 responses were expected.
- Registry migration added `detail` configuration for all five nodes in
  `/data/nodes.yaml`. Backup:
  `/data/nodes.yaml.pre-detail-v2-20260715T082859Z`.
- Fast scrape completed via Helm revision `15`; all five targets were up over
  the recorded 30-minute gate.
- Retention was changed independently via Helm revision `16` on chart
  `kube-prometheus-stack-86.3.1`. Runtime flags show `90d` and `40GiB`; fast
  targets were `5/5`, external targets `4/4`, and Prometheus was healthy and
  ready. The 60Gi PVC contained about 6.2Gi at the acceptance check.
