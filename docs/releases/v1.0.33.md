# NodeBeacon 1.0.33 production acceptance

## Release decision

- Release date: 2026-07-29 (Asia/Shanghai)
- Application image: `nodebeacon:git-8fc4c3a8ccd9`
- Application commit: `8fc4c3a8ccd9d1e145e999d18d3e34949e83417e`
- NodeBeacon Deployment revision: `72`
- Scope: revise the `/admin` navigation to the compact Komari-style button
  system while retaining NodeBeacon routes, icons, themes, i18n, and the
  existing mobile drawer infrastructure.
- No API, SQLite schema, Kubernetes resource, Secret, or monitoring behavior
  changed in this release.

## Validation completed

- Local gates passed: `pnpm lint`, `pnpm typecheck`, 95 API tests,
  `pnpm build`, Chromium Playwright suite (25/25), Kubernetes kustomize
  render, and `git diff --check`.
- The admin navigation Playwright coverage passed (4/4), including menu order,
  group ARIA state, route-driven expansion, mobile Escape/focus recovery, and
  the 240px desktop/264px mobile sidebar widths.
- `scripts/deploy.sh --plan` and `scripts/deploy.sh` completed the immutable
  image build, k3s import, rollout, readiness, and smoke checks.
- `scripts/verify-production.sh` passed. Production Deployment is `1/1`
  Ready and the deployed image annotation points to the exact application
  commit above.
- Real Chromium checks at `1440px` and `390px` verified the Chinese menu order,
  Traditional Chinese and English translations, absence of Monitor/Manage
  headings, expanded Settings/Notification groups, active-child behavior,
  route-driven group switching, dark/light themes, a settled mobile drawer at
  `x=0` with width `264px`, full-view scrim, Escape close, and focus recovery.
