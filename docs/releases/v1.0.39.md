- The active app build contains no `fonts.googleapis.com`, `fonts.gstatic.com`,
  Space Grotesk, Noto Sans, or JetBrains Mono references. The historical
  `apps/web/public/prototype/` artifact is intentionally unchanged.
- The release script completed the immutable image build, k3s import, rollout,
  readiness, health, status API, authentication config, and anonymous admin
  guard checks.
- `scripts/verify-production.sh` passed with Deployment availability `1/1`,
  all five nodes online, current backup freshness, required Prometheus rules,
  and the expected Cloudflare cache policy.
- Production browser checks at the default desktop viewport and 390px confirmed
  English, Simplified Chinese, Traditional Chinese, and metric monospace
  stacks; persisted language metadata; light and dark themes; no Google Fonts
  links or font faces; and no document horizontal overflow. The login page
  renders without overflow, and anonymous `/admin` correctly redirects to
  `/login`.
