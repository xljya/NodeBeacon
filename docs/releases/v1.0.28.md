# NodeBeacon 1.0.28 production acceptance

## Scope

Komari-style admin navigation and the v1.0.28 control-plane foundation:
SQLite schema v5, persistent Owner/password/TOTP/recovery codes, site/general
settings, server-selected JSON themes, Loki whitelist logs, data-source and
backup request status, notification/latency/remote intent APIs, and the
disabled-by-default executor manifests.

## Validation

- `pnpm lint` / `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `kubectl kustomize infra/k8s`
- `git diff --check`
- Chromium desktop/mobile checks (record exact production evidence after deploy)

## Rollback

Use the previous accepted deployment image and restore the pre-v5 SQLite
snapshot before starting the old binary. Remote functionality can be disabled
independently by leaving the executor at zero replicas and disabling targets.
