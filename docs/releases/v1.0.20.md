# NodeBeacon 1.0.20 production acceptance

## Release decision

- Release date: 2026-07-26 (Asia/Shanghai)
- Application image: `nodebeacon:git-3a77a55a0451`
- Application commit: `3a77a55a0451a22925228d4f89f3b5faa721781c`
- NodeBeacon Deployment revision: `56`
- Scope: replace the latency-series question-mark icon with the requested
  gray 16px Lucide `Info` icon for Zhejiang Mobile, Zhejiang Unicom, and
  Zhejiang Telecom, while removing the information action from `Ping`.
- The existing 28x28px interaction area is retained for the three carrier
  buttons. Their real RIPE Atlas statistics, keyboard behavior, tooltip,
  accessibility label, and on-demand API behavior are unchanged.
- Both the chart render boundary and the statistics component reject the
  `ping` vantage, preventing future layout or series-order changes from
  reintroducing the button.

## Validation completed

- Local gates passed: `pnpm lint`, `pnpm typecheck`, `pnpm test` (95 tests),
  `pnpm build`, `kubectl kustomize infra/k8s`, and
  `pnpm exec playwright test --project=chromium` (21 tests).
- Playwright asserts that the Ping statistics button count is zero, the
  carrier button count is three, and each carrier SVG has the `lucide-info`
  class, `16x16` dimensions, and `stroke="gray"`.
- `scripts/deploy.sh --plan`, `scripts/deploy.sh`, and
  `scripts/verify-production.sh` passed on RS1000.
- Production is `1/1 Ready`, runs the immutable image above, and carries the
  exact version and Git SHA annotations.
- Real Chromium verification passed at 1280px light theme and 390px dark
  theme in Simplified Chinese. Ping had no information control; all three
  carrier controls matched the requested SVG and opened real RIPE statistics.
  Both viewports had zero horizontal overflow.
- The only browser 4xx/console error was the documented anonymous
  `/api/auth/me` 401. No unexpected console error or failed response occurred.
