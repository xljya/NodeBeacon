# NodeBeacon 1.1.9 production acceptance

## Release decision

- Release date: 2026-08-24 (Asia/Shanghai)
- Application image: `nodebeacon:git-1264b6d2af6f`
- Application commit: `1264b6d2af6f7a15a072e9a118d9387e110e63ba`
- NodeBeacon Web commit: `6a676a09c0fe967da43dbc7176754c9c8a633f9c`
- NodeBeacon Deployment revision: `97`
- Scope: serve public `/nodes/:id` from the Komari-derived React 19 shell,
  vendor the in-shell detail page, keep `/instance/:id` as a 308 to
  `/nodes/:id`, and leave leftover React 18 assets only under `/legacy/`.
  No Komari RPC2 or Agent endpoints were added.

## Validation completed

- Local gates passed for the application commit: `pnpm lint` (zero errors; 24
  preserved upstream warnings), `pnpm typecheck`, 153 API tests, 13 frontend
  library tests, `pnpm build` including `scan:forbidden`, a clean
  `pnpm exec playwright test --project=chromium` run (39/39 on `E2E_PORT=4174`
  after port 4173 was occupied by an unrelated local `python -m http.server`),
  and `git diff --check`.
- `scripts/deploy.sh --plan` resolved version `1.1.9`, the complete application
  SHA, and immutable image `nodebeacon:git-1264b6d2af6f`. The full deployment
  script and `./scripts/verify-production.sh` then passed from the clean
  detached release checkout. Production reports 1/1 Ready.
- Real Chromium against production: homepage node names open `/nodes/rs1000`
  inside the public shell (`data-page="node-detail"`, no `.detail-main-content`).
  The page shows the node sidebar, CPU/RAM/disk usage, six whitelist charts,
  and latency stats with the existing 900 second RIPE interval. `/instance/rs1000`
  still returns 308 to `/nodes/rs1000`. The 390×844 viewport has no horizontal
  page overflow.

## Repository boundaries

- `xljya/NodeBeacon` is the main project and the only repository deployed to
  RS1000 and served on `monitor.liucf.com`. This release deployed only that
  repository.
- `xljya/NodeBeacon-Web` branch `nodebeacon` is a supporting, maintainable
  Komari-derived frontend source. Its exact commit
  `6a676a09c0fe967da43dbc7176754c9c8a633f9c` is vendored into NodeBeacon; the
  repository itself is not independently deployed to any machine or domain.
- `xljya/NodeBeacon1` is a supporting historical archive for the pre-migration
  project and infrastructure. It is not part of the current build or data
  plane and is not deployed to any machine or domain.
