# NodeBeacon 1.0.19 production acceptance

## Release decision

- Release date: 2026-07-26 (Asia/Shanghai)
- Application image: `nodebeacon:git-9e71f29b5564`
- Application commit: `9e71f29b556484b2509afb9957c1fb4968c42cdf`
- NodeBeacon Deployment revision: `55`
- Scope: add an on-demand information panel to each RIPE Atlas latency series,
  backed by the public raw measurement results for the last 24 hours.
- The panel reports real packet loss, min/max/average/latest RTT, P50, P99,
  population standard deviation, mean absolute inter-measurement variation,
  measurement counts, valid counts, received/sent packets, the configured
  interval, ICMP type, result time, and public RIPE measurement link.
- The browser receives only safe aggregates and public measurement/probe
  metadata. Target/probe addresses, API UUIDs, Prometheus access, and arbitrary
  query input remain outside the public contract.
- README, API documentation, RIPE operations documentation, and monitoring
  documentation now distinguish the 5-second browser/Prometheus fast path from
  the 300-second RIPE measurement cadence, 60-second collector poll, and RIPE
  `latest` endpoint cache behavior.
- The final UI uses an 18px Lucide information icon in a 28px interaction area.
  Revision `54` briefly ran v1.0.18 during acceptance and was immediately
  superseded by this final sizing correction before release closeout.

## Validation completed

- Local gates passed: `pnpm lint`, `pnpm typecheck`, `pnpm test` (95 tests),
  `pnpm build`, and `pnpm exec playwright test --project=chromium` (21 tests).
- The node-detail browser test confirms statistics are fetched only after the
  information icon is opened, verifies the real-statistics fields, closes the
  panel by keyboard, and asserts the 18px/28px icon geometry.
- RIPE statistics unit tests verify packet-level calculation, configured
  measurement/probe filtering, public-results query parameters, and rejection
  of unknown node/vantage combinations. Route tests cover validation, public
  node visibility, and unavailable configuration errors.
- `kubectl kustomize infra/k8s`, `scripts/deploy.sh --plan`,
  `scripts/deploy.sh`, and `scripts/verify-production.sh` passed.
- Production is `1/1 Ready`, runs the immutable image above, and carries the
  exact version and Git SHA annotations.
- All four production statistics endpoints (`Ping / 浙江移动 / 浙江联通 /
  浙江电信`) returned non-null real statistics with their configured public
  probe and measurement IDs, `ICMP`, a `300s` interval, a 24-hour window, and
  distinct received/sent and valid-measurement counts.
- Real Chromium verification passed at 1280px light theme and 390px dark
  theme in Simplified Chinese. Both viewports displayed the raw RIPE statistics,
  computed the information control at 28x28px with an 18px icon, and had zero
  horizontal overflow.
- The only browser 4xx/console error was the documented anonymous
  `/api/auth/me` 401. No unexpected console error or failed response occurred.
