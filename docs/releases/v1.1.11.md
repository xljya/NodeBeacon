# NodeBeacon 1.1.11 production acceptance

## Release decision

- Release date: 2026-08-24 (Asia/Shanghai)
- Application image: `nodebeacon:git-5b25560dccf3`
- Application commit: `5b25560dccf3c8a4b19039d7ef1a6f31caf710b8`
- NodeBeacon Web commit: `a1c6856f58e16884630d48cf909abceda5160a4f`
- NodeBeacon Deployment revision: `99`
- Scope: Epic B Owner-admin completeness. Unreachable Komari plugin, terminal,
  market, pprof and RPC2 source was removed from the React 19 shell. Traffic
  reports, metrics and notification overview now use the existing Owner REST
  APIs. Exec shows executor status and remains allow-listed only. No Komari
  RPC2, Agent, WebSSH or free-form shell endpoints were added.

## Repository boundaries

- `xljya/NodeBeacon` is the main project and the only repository deployed to
  RS1000 and served on `monitor.liucf.com`. This release deployed only that
  repository.
- `xljya/NodeBeacon-Web` branch `nodebeacon` is a supporting, maintainable
  Komari-derived frontend source. Its exact commit
  `a1c6856f58e16884630d48cf909abceda5160a4f` is vendored into NodeBeacon;
  the repository itself is not independently deployed to any machine or domain.
- `xljya/NodeBeacon1` is a supporting historical archive for the pre-migration
  project and infrastructure. It is not part of the current build or data
  plane and is not deployed to any machine or domain.
