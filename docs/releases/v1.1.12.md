# NodeBeacon 1.1.12 production acceptance

## Release decision

- Release date: 2026-08-24 (Asia/Shanghai)
- Application image: `nodebeacon:git-f95b76d0207c`
- Application commit: `f95b76d0207c3271ffeeaf17b637261411b8edef`
- NodeBeacon Web commit: `167a30494fe6ea819113be31aac917bddf6c117d`
- NodeBeacon Deployment revision: `100`
- Scope: Epic C product-surface decision. The Owner Exec menu and queue page
  were withdrawn because the executor is still a disabled placeholder
  (`replicas: 0`, `/run` returns 503). `/admin/exec` now redirects to the
  dashboard. Owner-only remote APIs remain; no WebSSH, free-form shell or
  Komari RPC2 was added. A future `netcup-1o` canary still requires a real
  allow-listed worker, TOTP, output limits and audit evidence.

## Validation completed

- Local gates passed for the application commit: `pnpm lint` (zero errors; 10
  remaining upstream warnings), `pnpm typecheck`, 141 API tests, 14 frontend
  library tests, `pnpm build` including `scan:forbidden`, a clean
  `pnpm exec playwright test --project=chromium` run (30/30 against the API
  on port 3001), and `git diff --check`.
- `scripts/deploy.sh --plan` resolved version `1.1.12`, the complete application
  SHA, and immutable image `nodebeacon:git-f95b76d0207c`. The full deployment
  script and `./scripts/verify-production.sh` then passed from the clean
  detached release checkout. Production reports 1/1 Ready. Executor remains
  at 0 replicas.
- Production HTML for `/` is the React 19 SPA (`entry-index-DWc_xL3d.js`).
  That entry bundle contains no `ExecPage`, `Queue task` or `/api/rpc2`
  string. `/admin/exec` still returns the same SPA HTML (anonymous visitors
  are sent to login by AdminLayout, then redirected to dashboard).

## Repository boundaries

- `xljya/NodeBeacon` is the main project and the only repository deployed to
  RS1000 and served on `monitor.liucf.com`. This release deployed only that
  repository.
- `xljya/NodeBeacon-Web` branch `nodebeacon` is a supporting, maintainable
  Komari-derived frontend source. Its exact commit
  `167a30494fe6ea819113be31aac917bddf6c117d` is vendored into NodeBeacon;
  the repository itself is not independently deployed to any machine or domain.
- `xljya/NodeBeacon1` is a supporting historical archive for the pre-migration
  project and infrastructure. It is not part of the current build or data
  plane and is not deployed to any machine or domain.
