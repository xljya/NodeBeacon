# NodeBeacon 1.0.32 release

The terminal boundary now supports a one-time, 60-second TOTP ticket and a
WebSocket route with Origin/Cookie checks, two-session concurrency limit,
single-use ticket consumption and a disabled-executor close path. nginx has a
dedicated no-buffering, long-timeout WebSocket location. The executor and SSH
targets remain disabled until the canary acceptance.

Release evidence and the exact production SHA are appended after deployment.
