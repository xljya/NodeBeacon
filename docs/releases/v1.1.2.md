# NodeBeacon 1.1.2 production acceptance

## Release decision

- Release date: 2026-08-13 (Asia/Shanghai)
- Application image: `nodebeacon:git-31ac0f8598f5`
- Application commit: `31ac0f8598f5ed0d9bcca3a9aebaa675bb77d5c0`
- NodeBeacon Web commit: `375ca5baf437b53da29cec54817c528a6f41cf55`
- NodeBeacon Deployment revision: `89`
- Scope: ship the adapted Komari Admin shell as a shadow Owner UI on
  `/admin-v2` and `/login-v2` while keeping the live `/admin` and `/login`
  React 18 shells unchanged. Fastify, Prometheus, SQLite, authentication, and
  the existing management APIs remain the only data plane. No Komari RPC2 or
  `/api/admin/client/*` compatibility layer was added.

## Validation completed

- Local gates passed: `pnpm lint` (zero errors; 24 preserved upstream
  warnings), `pnpm typecheck`, 117 API tests plus 4 Admin gateway/path tests,
  `pnpm build` including `scan:forbidden`,
  `pnpm exec playwright test --project=chromium` (45/45), and
  `git diff --check`.
- Shared contracts now cover site, theme, notification, traffic-report, probe,
  log, backup, and remote-task DTOs. Fastify gained
  `PATCH`/`DELETE /api/admin/traffic-reports/:id` with Owner, Origin, and audit
  coverage. Public `/api/status` whitelist tests remain green.
- Shadow Playwright confirmed an unauthenticated `/admin-v2/servers` deep link
  lands on `/login-v2?next=/admin-v2/servers`, password login returns to the
  requested page, the desktop sidebar opens Servers, mobile layout has no
  horizontal overflow, and no `/api/rpc2` traffic is emitted.
- `scripts/deploy.sh --plan`, the full deployment script, and
  `scripts/verify-production.sh` passed for the exact release commit. Official
  verification confirmed 1/1 availability, 5/5 nodes online, authentication
  boundaries, cache policy, backup freshness, and Prometheus rules.
- Production NodePort checks: `/api/rpc2`, `/api/admin/client`, `/api/me`, and
  `/api/logout` return 404; unauthenticated `/api/admin/summary` and
  `/api/admin/nodes` return 401. Unauthenticated foreign-origin mutation is
  rejected at the auth gate (401); Origin 403 remains covered by API tests.
- Real Chromium at `https://monitor.liucf.com` confirmed `/login-v2` renders
  the Komari login card, `/admin-v2/dashboard` redirects to a sanitized
  `/login-v2?next=/admin-v2/dashboard`, official `/admin` still uses the
  legacy login shell, and the public home page stays 5/5 online. Desktop
  `1440x1000` and mobile `390x844` had zero document overflow, zero forbidden
  API calls, and zero console errors. Production evidence contains no
  passwords, cookies, private IPs, labels, or owner notes.
- Owner-authenticated page CRUD was accepted against the assembled production
  bundle in local Playwright and API tests. Live owner cookies were not used
  for production screenshots.

## Repository boundaries

- `xljya/NodeBeacon` is the product, release, and deployment repository.
- `xljya/NodeBeacon-Web` branch `nodebeacon` is the adapted frontend source.
  This release vendors Web commit `375ca5baf437b53da29cec54817c528a6f41cf55`.
- `xljya/NodeBeacon1` remains the historical NodeBeacon infra source repository
  and was not modified.
- Komari Web provenance and acknowledgements remain documented. Using the
  Admin shell does not introduce Komari backend protocols. Formal `/admin`
  cutover is reserved for v1.1.3; leftover React 18 Admin cleanup is reserved
  for v1.1.4.
