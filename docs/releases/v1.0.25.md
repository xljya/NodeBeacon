# NodeBeacon 1.0.25 production acceptance

## Release decision

- Release date: 2026-07-26 (Asia/Shanghai)
- Application image: `nodebeacon:git-0a91b389217d`
- Application commit: `0a91b389217d6d9918f1d0e379938c7b192879c3`
- NodeBeacon Deployment revision: `61`
- Scope: make the Zhejiang Mobile, Zhejiang Unicom, and Zhejiang Telecom
  latency information controls behave like the Komari reference: desktop
  pointer hover opens the real statistics panel, moving into the panel keeps
  it open, and leaving the trigger and panel restores the chart.
- A 120ms close buffer bridges the trigger-to-panel gap without pinning the
  panel open. The real RIPE Atlas request remains lazy and is reused after the
  first successful load.
- Touch and keyboard input remain first-class: touch taps toggle the panel,
  the close control handles touch pointer completion without synthetic-hover
  reopening, Enter opens it, and Escape closes it.
- On viewports at or below 720px the panel is portalled to the themed public
  status-page root. This keeps its fixed 12px viewport margins, full readable
  width, theme variables, and pointer access independent of dnd-kit card
  transforms and overflow.

## Validation completed

- Local gates passed: `pnpm lint`, `pnpm typecheck`, `pnpm test` (95 tests),
  `pnpm build`, `kubectl kustomize infra/k8s`, and
  `pnpm exec playwright test --project=chromium` (22 tests).
- Playwright covers desktop hover-open, panel hover retention, pointer-leave
  close, keyboard reopen/Escape, one-request caching, and a real touch context
  that verifies fixed positioning, non-transparent theme background, width
  greater than 300px, and touch close behavior.
- `scripts/deploy.sh --plan`, `scripts/deploy.sh`, and
  `scripts/verify-production.sh` passed on RS1000.
- Production is `1/1 Ready`, runs the immutable image above, and carries the
  exact version and Git SHA annotations.
- Real production Chromium verification passed against
  `https://monitor.liucf.com/nodes/rs1000`: three carrier information buttons
  were present, the Zhejiang Mobile statistics API returned HTTP 200 with
  RIPE Atlas content, the desktop panel stayed open across trigger-to-panel
  movement and closed on leave, and the touch panel opened at 366px wide with
  fixed positioning and an opaque themed background before closing by tap.
