# NodeBeacon 1.1.7 production acceptance

## Release decision

- Release date: 2026-08-14 (Asia/Shanghai)
- Application image: `nodebeacon:git-9d4bdd2d2e60`
- Application commit: `9d4bdd2d2e60b64d54995c5b722a11e70a9fa7f7`
- NodeBeacon Web commit: `1de4948054d591bd39fa71e9f4ffcba00a898da5`
- NodeBeacon Deployment revision: `95`
- Scope: stop painting the empty React 19 public layout when opening a node
  from `/`. Homepage cards and table names now link directly to `/nodes/:id`.
  Fastify issues HTTP 308 from `/instance/:id` to `/nodes/:id` for bookmarks
  and old Komari-style URLs. The public-shell `/instance/:id` route is kept
  only as a layout-free fallback. No Komari RPC2 or Agent endpoints were
  added.

## Validation completed

- Local gates passed for the application commit: `pnpm lint` (zero errors; 24
  preserved upstream warnings), `pnpm typecheck`, 152 API tests, 11 frontend
  library tests, `pnpm build` including `scan:forbidden`, a clean
  `pnpm exec playwright test --project=chromium` run (47/47), and
  `git diff --check`. New coverage includes `getNodeDetailPath`, Fastify
  `/instance/:id` 308 cases, and the public-shell e2e handoff.
- `scripts/deploy.sh --plan` resolved version `1.1.7`, the complete application
  SHA, and immutable image `nodebeacon:git-9d4bdd2d2e60`. The full deployment
  script and `./scripts/verify-production.sh` then passed from the clean
  detached release checkout. Production reports 1/1 Ready and 5/5 nodes
  online.
- Origin NodePort and `https://monitor.liucf.com/instance/rs1000` both return
  HTTP 308 with `Location: /nodes/rs1000`.
- Real Chromium against production: homepage has five `/nodes/` card links and
  zero `/instance/` links; clicking the first card lands on
  `/nodes/rs1000` with `.detail-main-content` visible and `.km-footer` absent.
  Opening `/instance/rs1000` follows the 308 to the same detail page. Mobile
  `390x844` overflow is 0.

## Repository boundaries

- `xljya/NodeBeacon` is the main project and the only repository deployed to
  RS1000 and served on `monitor.liucf.com`. This release deployed only that
  repository.
- `xljya/NodeBeacon-Web` branch `nodebeacon` is a supporting, maintainable
  Komari-derived frontend source. Its exact commit
  `1de4948054d591bd39fa71e9f4ffcba00a898da5` is vendored into NodeBeacon; the
  repository itself is not independently deployed to any machine or domain.
- `xljya/NodeBeacon1` is a supporting historical archive for the pre-migration
  project and infrastructure. It is not part of the current build or data
  plane and is not deployed to any machine or domain.
