# NodeBeacon 1.0.29 release

This release extends the admin foundation with notification channel/rule
management UI, encrypted Telegram/SMTP/HTTPS Webhook delivery outbox and
retry history, central HTTP/TCP/ICMP probe management, and the allow-listed
remote runbook console. The executor remains disabled at zero replicas until
the v1.0.31 canary acceptance.

Release evidence and the exact production SHA are appended after deployment.
